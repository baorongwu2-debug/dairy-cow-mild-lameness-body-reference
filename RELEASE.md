# GitHub and permanent archiving

This package is prepared locally; neither GitHub publication nor a Zenodo DOI is implied by its contents. Author names follow the current manuscript. No email, ORCID, grant identifier or institutional ethics determination has been invented.

1. Upload this repository to the author's intended public GitHub repository.
2. Confirm author metadata and code licensing, then run `python scripts/verify_results.py`.
3. Connect GitHub in Zenodo and enable archiving for this repository.
4. Create the GitHub release `v1.0.0`. Wait for Zenodo to process it and inspect the actual record.
5. Add the real record DOI to `CITATION.cff` and the manuscript data-availability statement. Never substitute an example DOI.

Official guide: https://help.zenodo.org/docs/github/archive-software/github-upload/

The funding designation is recorded in README. A grant number was not supplied. Institutional review determination, personal contributions and competing-interest declarations are author declarations, not generated by archiving this software.
